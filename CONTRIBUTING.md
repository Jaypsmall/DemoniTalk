# Contributing to DemoniTalk

Thank you for your interest in contributing to **DemoniTalk**! We welcome bug reports, feature suggestions, and code contributions from the community.

---

## How Can I Contribute?

### 1. Reporting Bugs
Before opening a new issue, please search existing issues to avoid duplicates. When reporting a bug, include:
- A clear and descriptive title.
- Steps to reproduce the behavior.
- Android OS version, device model, and app version.
- Expected vs. actual behavior.

### 2. Suggesting Enhancements
Feature requests are always welcome! Please open an issue with the tag `enhancement` describing:
- The problem or use case you are trying to solve.
- Your proposed solution or desired behavior.

### 3. Submitting Code (Pull Requests)
We follow a standard Git feature-branch workflow:

1. **Fork the Repository:** Create a personal fork of DemoniTalk on GitHub.
2. **Create a Branch:** Create a descriptive branch for your fix or feature from `main`.

   git checkout -b feature/voice-command-fix
